Windows

What is the PATH environment variable? 🧭

When you type python into a terminal, Windows looks through a list of folders to find a program named python.exe. That list is called PATH.

Before installing Python (PATH):

# Folders Windows searches: C:\Windows\system32 C:\Windows C:\Windows\System32\Wbem ... # No python here → "not recognized"

After ticking the checkbox:

# Folders Windows searches: C:\Windows\system32 C:\Windows C:\Users\You\...\Python312\Scripts\ C:\Users\You\...\Python312\ # ✅ python.exe lives in one of these

The "Add Python to PATH" checkbox just does this 👇

It adds Python's install folder to your PATH list. Once there, typing python anywhere works — Windows finds python.exe and runs it.

💡 PATH isn't Python-specific. Every program you run from the terminal (git, node, code, etc.) lives in a folder that's on PATH.

Windows: quick fixes 🔧

"python is not recognized"

PATH wasn't set. Easiest: uninstall Python from Settings → Apps, then reinstall and TICK "Add to PATH". Or follow slides 9–10.

The Microsoft Store opens when I type python

Windows has a "python.exe" stub that opens the Store. Fix: Settings → Apps → Advanced app settings → App execution aliases → turn OFF the two Python entries.

pip install X says "permission denied"

Use pip install --user X, OR re-open Command Prompt as Administrator.

Multiple Python versions installed?

Use py -3.12 or py -3.11 to pick. The py launcher is bundled with Python on Windows.

VSCode doesn't see my Python

Press Ctrl+Shift+P → type "Python: Select Interpreter" → pick the version you installed.

Antivirus blocking the installer

Both python.org and code.visualstudio.com are official sources — temporarily disable real-time scanning if needed, or whitelist the file.

macOS

Verify Python + understand ~/.zshrc ✅

In Terminal, run these:

your-mac ~ % python3 --version
Python 3.12.X

your-mac ~ % pip3 --version
pip 24.X.X from ... (python 3.12)

your-mac ~ % which python3
/usr/local/bin/python3      # python.org installer
— or —
/opt/homebrew/bin/python3   # Homebrew on Apple Silicon

Want plain python to also work? Add an alias to ~/.zshrc:

macOS uses the zsh shell. Its config file is ~/.zshrc in your home folder. PATH and aliases live there.

your-mac ~ % echo 'alias python=python3' >> ~/.zshrc
your-mac ~ % echo 'alias pip=pip3' >> ~/.zshrc
your-mac ~ % source ~/.zshrc
your-mac ~ % python --version
Python 3.12.X    # ✅ plain "python" now works
💡 ~/.zshrc runs every time you open a new Terminal. PATH changes, aliases, environment exports — all go here. To open it in VSCode later: code ~/.zshrc.

If something goes wrong 🩹

The Run ▶ button doesn't appear

VSCode hasn't recognized this as a Python file. Save it with a .py extension. Also confirm the Python extension is installed and enabled.

"No Python interpreter selected"

Ctrl/⌘+Shift+P → "Python: Select Interpreter" → pick the version you installed.

VSCode opens the Microsoft Store on Windows

Disable "App execution aliases" for Python (Settings → Apps → Advanced app settings).

"ModuleNotFoundError: No module named 'X'"

Run pip install X (Windows) or pip3 install X (Mac) in the terminal. We won't need this for Day 1.

Wrong Python version is being used

Different ways Python is found can conflict. Check which python3 (Mac) or where python (Windows) — it shows which one is being picked.

Terminal in VSCode is wrong shell

Ctrl/⌘+Shift+P → "Terminal: Select Default Profile" → pick PowerShell (Win) or zsh (Mac).

🆘 Still stuck? Copy the exact error message into Google. 99% of the time, the first Stack Overflow result has your fix. Senior devs do this every day.
